In ./web, add a "Quiet hours" panel to the selected home's view.

It shows the last 24 hours as a strip of 24 cells, one per hour, oldest on the left. Each cell is coloured by the worst thing that started in that hour: noise is the most serious, then occupancy, then a device going offline, and an hour with nothing in it stays neutral. The user has to be able to find out what a cell means without a mouse, and it has to still be readable on a phone.

Use what's already in the app. Don't add dependencies.
