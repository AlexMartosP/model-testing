## The detail that makes it a 3

It trims **before** testing for emptiness:

```ts
const email = contact.email.trim().toLowerCase();
if (email.length > 0) { emails.add(email); }
```

The prompt says "skip empty emails". The naive order is to test `email === ""` first, which lets
`"   "` through and then stores it as `""`. Doing it in this order means whitespace-only addresses
are skipped as well, which is what "skip empty" has to mean for the output to be usable. Small, and
the most likely place to get this task subtly wrong.

Also correct: `.sort()` with no comparator is lexicographic, which is right here because every
string has already been lowercased, so there is no uppercase-before-lowercase surprise.
