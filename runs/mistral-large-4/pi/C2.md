Written to `hero.html`. Key semantic choices:

- **Eyebrow** is a plain `<p>` — not the heading, so the H1 stays unique.
- **Headline** is the single `<h1 id="hero-heading">`, and the `<section aria-labelledby="hero-heading">` ties the section to it for assistive tech.
- **Subline** is a `<p>`.
- **CTAs** are real `<a href>` links (they navigate, so links are correct even when visually button-like; with no CSS they render as plain links).
