Here's a one-liner (verified working):

```bash
du -ah /var/log 2>/dev/null | sort -rh | head -10
```

This lists the 10 largest entries (files **and** directories) with human-readable sizes. Note the top hit is `/var/log` itself since `du` aggregates directories.

If you want **files only**, use:

```bash
find /var/log -type f -exec du -h {} + 2>/dev/null | sort -rh | head -10
```
