## Every technical claim checks out

This is worth recording because it breaks the pattern from T2 and T4.

| Claim | Verdict |
|---|---|
| `dig yourdomain.com A +ttlunits` | **Real.** `+ttlunits` is documented in BIND 9: TTLs in s/m/h/d/w units. It is rejected by macOS's bundled dig 9.10.6, which is simply old, so the advice is right and the local binary is the limitation. |
| `dig yourdomain.com @your-authoritative-nameserver` | correct syntax for querying the source directly |
| whatsmydns.net for per-resolver checks | real, and the right tool for this |
| "Some resolvers don't strictly honor short TTLs" | true, some clamp a minimum |
| 86400s = 24h | correct |

No invented flags, no invented tools. T2's JWE heading and T4's resolver clause were both unhedged
precision errors; there is no equivalent here.
